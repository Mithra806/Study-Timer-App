# Lock In Time App
Lock In Time is an aesthetic study app with warm colors. It is designed to help anyone stay productive. It features three sections, a to do list, a calendar, and a Pomodoro timer. Your to do list and calendar progress is saved automatically, so even if you close the tab your data will still be there when you come back!
